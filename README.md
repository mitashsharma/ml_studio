🤖 ML Studios

ML Studios is a beginner-friendly machine learning web application that allows users to upload datasets, train models, and view results through a simple interface.

🚀 Features

- 📁 Upload dataset (CSV format)
- 🧠 Train machine learning models
- 📊 View results and accuracy
- 🌐 Simple web interface using Flask
- 📂 Organized project structure for scalability

🛠️ Tech Stack

- Python 🐍
- Flask 🌐
- HTML, CSS 🎨
- Machine Learning (custom model / scikit-learn)

📂 Project Structure

ML_Studios/

│── backend/

⚙️ Installation

1. Clone the repository:

git clone https://github.com/your-username/ml-studios.git
cd ml-studios

2. Install dependencies:

pip install -r requirements.txt

3. Run the app:

python app.py

4. Open in browser:

http://127.0.0.1:5000/
